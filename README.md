# Number Guessing Game

A Python terminal game for practising loops, conditions, user input, random numbers, functions, and validation.

## Run the game

Open a terminal inside this folder and run:

```bash
python game.py
```

If your computer requires `python3`, run:

```bash
python3 game.py
```

This project uses only Python's standard library, so you do not need to install any packages or activate a virtual environment.

## How to play

1. Select Easy, Medium, or Hard.
2. Enter a whole number within the displayed range.
3. Use the “too high” and “too low” hints.
4. Guess before your attempts run out.
5. Choose whether to play another round.

## Run the tests

```bash
python -m unittest discover -s tests -v
```
